# Kamaji Tasks

Static GitHub Pages site (home page and privacy policy) for the private, personal-use
"Kamaji Tasks" Google OAuth app, which lets the Kincaid family's assistant manage their
own Google Tasks lists.

- Home: https://nuxvomo.github.io/kamaji-tasks/
- Privacy policy: https://nuxvomo.github.io/kamaji-tasks/privacy.html

Plain HTML, no build step. Contains no credentials.
