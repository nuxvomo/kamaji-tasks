Kamaji Tasks Privacy Policy

Effective date: October 19, 2026

Kamaji Tasks is a private, personal-use tool operated by Jim Kincaid for the Kincaid family. It is not offered to the public.

Data we access

Kamaji Tasks accesses only Google Tasks data, plus the account's email address to confirm which account is connected, and only for Google accounts the owner has authorized.

How data is used

This data is used only to manage those task lists for the family (creating, updating and completing tasks). It is not sold, not shared with third parties, and not used for advertising.

Storage

OAuth tokens are stored privately on the owner's own machine and are not shared with anyone.

Google API Services User Data Policy

Kamaji Tasks' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke Kamaji Tasks' access at any time at myaccount.google.com/permissions.
